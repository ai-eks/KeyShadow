# macOS 使用说明

支持 macOS 13+，Apple Silicon / Intel。打开 DMG，将 `键影.app` 拖入 `Applications` 后打开；程序驻留菜单栏，不常驻 Dock。首次运行显示权限说明。

界面设置、输入行为与快捷键统一见 [通用操作](../../README.md#通用操作)。以下仅说明 macOS 差异。

## 权限与输入法

从菜单栏键影图标 →「权限设置」查看实际授权状态：

| 权限 | 用途与缺失时的行为 |
| --- | --- |
| 输入监控 | 监听实体按键；未授权时无按键高亮，常驻模式仍可查看静态键位。授权后尝试恢复监听；系统要求时退出并重新打开 |
| 辅助功能（可选） | 识别密码框、只读区域及光标位置。缺少权限时按通用文档中的未知状态处理，自动位置依靠最近点击或保存的位置 |

不需要屏幕录制权限。系统安全键盘输入会停止动态提示；没有辅助功能权限时不能可靠识别密码框。全局监听只被动接收事件，不拦截或重发按键。

中英文状态按系统当前输入源的语言判断，ABC / 英文输入源与 Caps Lock 按英文处理。部分第三方输入法的内部英文模式不改变系统输入源，可能仍有提示；此时切换到系统 ABC，或用快捷键关闭提示。不同应用使用同一套状态识别与定位逻辑。

## 登录启动与配置

从菜单勾选「登录时启动」，默认关闭，通过 `SMAppService` 注册；系统待批准时菜单显示实际状态，请在系统设置中处理。

设置保存在当前用户的 `uy.aix.keyshadow` 偏好中，旧版本缺少的项目使用默认值。移除前取消登录启动，再删除应用。

## 签名与实机范围

本地构建默认临时签名、未公证；网络下载的构建可能需要在系统「隐私与安全性」中确认打开，无需关闭 Gatekeeper。正式版本的签名、公证配置见仓库的打包与发布文档。

桌面测试使用真实 NSPanel 和受控输入；`--privacy` 通过实际 AX 接口检查自建 AppKit / WebKit 输入框。真实全局监听、各编辑器光标接口、登录启动及 Intel 机器运行仍需对应实机验收。
