# Windows 使用说明

需要 Windows 10 / 11 与 .NET Framework 4.8。将 `键影.exe` 放在固定的本地目录并双击运行，无需安装开发工具或额外包。

界面设置、输入行为与快捷键统一见 [通用操作](../../README.md#通用操作)。以下仅说明 Windows 差异。

## 托盘与快捷键

程序驻留系统托盘。双击「键 / 影」图标可恢复可操作预览；如果快捷键被其他软件占用，菜单会显示「快捷键被占用」，仍可从托盘或再次运行 EXE 恢复。

## 开机启动

在键盘或托盘右键菜单勾选「开机启动」，默认关闭，仅对当前用户生效，无需管理员权限。退出程序不取消启动项；取消勾选才会移除。

启动项位于 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`，值名为 `keyshadow`，命令是带引号的 EXE 完整路径加 `--startup`。移动或重命名程序后，从新位置运行并重新勾选以更新路径；路径过长或注册失败时保留原启动项。如果曾在 Windows「启动应用」中禁用，还需在那里重新启用。重复登录启动不会展开已有实例。

## 输入法与定位

读取前台窗口的输入法开启状态和中文转换模式，已验证微软拼音。其他输入法依赖同一接口；键盘布局为中文但状态读取失败或超时时按中文输入处理。开启 Caps Lock 按英文状态处理，不主动切换输入法。

定位使用 Win32 光标、MSAA 和 UI Automation。仅查询焦点、几何位置、可写状态与密码属性；浏览器等共用窗口句柄的控件会在按键后重新检查，检查期间暂不绘制提示，焦点变化则重新检查。查询超过 650 毫秒按通用文档中的未知状态处理。

只监测普通桌面的实体按键，忽略软件注入事件；系统安全桌面、管理员窗口及特殊编辑器不保证可用。支持逐显示器 DPI 缩放，跨屏效果需对应设备实测。

## 配置与移除

设置保存在 `%LOCALAPPDATA%\keyshadow\settings.txt`；开机启动单独保存在注册表。旧配置缺少的项目使用默认值。

移除前先取消「开机启动」，再删除程序文件。删除上述配置文件可重置其他设置。
