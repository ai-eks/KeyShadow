# 项目结构

Windows 使用 C# 5 / WinForms，macOS 使用 Swift / AppKit；两端保留各自原生窗口、按键监听和系统接口，共用品牌、方案与配色。

```text
KeyShadow/
├── apps/windows/
│   ├── src/              窗口、双拼逻辑与系统接口
│   ├── tests/            方案、窗口、渲染、输入法与隐私测试
│   ├── assets/           Windows 图标
│   └── tools/            构建、测试、打包与图标生成
├── apps/macos/
│   ├── Sources/KeyShadow/     AppKit 界面与系统接口
│   ├── Sources/KeyShadowCore/ 双拼、设置及生成资源
│   ├── Tests/            核心测试与独立隐私测试窗口
│   ├── assets/           Info.plist
│   └── tools/            数据同步、构建、测试与通用 DMG 打包
├── shared/branding/      SVG / PNG 品牌资源
├── docs/
│   ├── 构建与测试.md      开发环境与验证命令
│   ├── windows/、macos/   安装及平台差异
│   ├── screenshots/      实际窗口绘制与截图
│   ├── changelog.json    双语更新日志，生成 Release 正文并供主页读取
│   └── 其他文档           方案来源、项目结构、打包与发布
├── tools/changelog.py    更新日志校验与 Release 正文生成
├── README.md             下载入口、界面预览与通用操作
├── VERSION               三段数字版本
└── dist/                 构建及分发产物，不纳入版本控制
```

Windows C# 源码是方案表、411 个音节和配色的事实来源；`python3 apps/macos/tools/sync-pinyin.py` 生成 macOS JSON 资源。修改数据后重新生成并一同提交；测试和 CI 的 `--check` 防止漂移。Swift 编码器独立实现，复用 Windows 的预期样例验证音节往返与双键组合。

脚本按自身位置解析路径，Windows 可从本地目录或 WSL UNC 路径执行。临时文件放在各平台的 `.build/` 中，由 Git 忽略。Windows 图标可运行 `apps/windows/tools/GenerateIcon.ps1` 重新生成。
