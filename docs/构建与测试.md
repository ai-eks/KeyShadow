# 构建与测试

所有命令在仓库根目录执行。

Windows PowerShell：使用系统自带的 .NET Framework C# 5 编译器，无需下载依赖。

```powershell
powershell -ExecutionPolicy Bypass -File .\apps\windows\tools\Test.ps1
powershell -ExecutionPolicy Bypass -File .\apps\windows\tools\Build.ps1
```

macOS：需要 Swift 5.9+、Xcode 或 Command Line Tools、Python 3，无第三方包依赖。

```bash
apps/macos/tools/test.sh
apps/macos/tools/build.sh
open dist/macos/键影.app
```

构建产物为 `dist/windows/键影.exe` 与 `dist/macos/键影.app`。Windows 可用 `Build.ps1 -OutputDirectory <目录>` 指定输出目录。

| 验证 | Windows `Test.ps1` 参数 | macOS `test.sh` 参数 |
| --- | --- | --- |
| 方案与核心数据 | 不加参数 | 不加参数；同时检查与 Windows 的方案、配色同步 |
| 窗口、显示、定位、计时与渲染 | `-Desktop`，包含原生 / WPF 密码框 | `--desktop`，使用受控按键和隐私结果 |
| 真实输入法状态 | `-Ime`，微软拼音默认 Shift 切换、Caps Lock 关闭 | 需实机验证当前输入源与第三方输入法 |
| 浏览器 / 系统输入框隐私 | `-Browser`，Edge 访客模式与独立空白表单 | `--privacy`，已有辅助功能权限下的 AppKit / WebKit 空白输入框 |

桌面验证前退出键影，期间不要操作键鼠；测试会恢复配置，不读取现有页面、账号或真实密码。受控场景通过不代表所有输入法、编辑器和多屏环境都已实机验证。
